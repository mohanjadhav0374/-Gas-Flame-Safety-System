# Gas, Smoke & Flame Detection with Automatic Safety Response 🚨🔥

## 📌 About
This project detects **LPG leakage, smoke, and flame** using MQ-2 sensor & flame sensor.  
On detection, it activates safety systems like **fan, solenoid valve, buzzer, and water pump**.

## ⚡ Features
- Gas detection using MQ-2 sensor  
- Flame detection using IR flame sensor  
- Automatic fan and valve control  
- Buzzer + LED alerts  
- Water pump activation on fire  

## 🛠 Components Used
- Arduino UNO  
- MQ-2 Gas Sensor  
- Flame Sensor  
- Buzzer  
- 2 LEDs (Red & Blue)  
- Relay Module  
- Fan, Motor Pump, Solenoid Valve  

## 🚀 How to Run
1. Open `main.ino` in Arduino IDE  
2. Select correct COM port & board (Arduino UNO)  
3. Upload the code  
4. Power the system & test with flame/gas
